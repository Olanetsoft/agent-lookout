# Code of conduct

This applies to issues, pull requests and any other place where people work on Agent Lookout.

Be kind and be patient. People arrive with different experience, different first languages and different amounts of spare time.

Criticise the code or the idea and leave the person out of it. Give your reasons, and assume the other person had reasons too.

Harassment, insults, sexual language or imagery, and publishing someone's private information are not acceptable here. That includes session names, folder paths and screenshots from another person's machine, posted without their consent.

The maintainer may edit or remove comments, close threads and block accounts that break these rules.

## Reporting a problem

Contact the maintainer, Idris Olubisi, privately, using the contact details on the [Olanetsoft GitHub profile](https://github.com/Olanetsoft). Say what happened and where, with links if you have them. The report stays between you and the maintainer.

For a security vulnerability, follow [SECURITY.md](SECURITY.md) instead.
