What it does

It finds the sessions already running

It reads the list of sessions Claude Code keeps on your Mac and the session files Codex saves. A session in a terminal, in VS Code or in a desktop app appears with no setup. Agent Lookout starts nothing.

Working 3

  • billing-webhooks Claude Code Terminal working for 5m
  • api-rate-limits Codex Desktop app working for 12m
  • search-indexing Claude Code VS Code working for 31m

Idle 2

  • docs-site Claude Code Terminal idle for 18m
  • mobile-onboarding Codex Desktop app idle for 1h 05m

It shows which one needs you

A Claude Code session that stops for permission or asks you a question moves to the top of the page, with its reason and a timer. The browser tab counts the sessions that are waiting, as in (1) Agent Lookout, and a notification can tell you when one starts waiting.

Nothing needs you the lamp in the mark is out
A session is waiting the lamp is lit, on every view

Codex does not record that it is waiting, so a Codex session shows as working, idle or finished.

It sends nothing anywhere

It does run Claude Code’s own listing command, which may contact Anthropic the way Claude Code normally does. PRIVACY.md lists everything it reads and runs.

How to get it

There is no download yet. Agent Lookout runs from its repository with Node.js, and opens as a page in your browser.

View on GitHub
  1. 1

    Check what you have

    You need Node.js 20.19 or newer (on Node 22, 22.12 or newer), and Claude Code, Codex or both. 

    node --versionclaude --versioncodex --version
  2. 2

    Clone it and install what it needs

    git clone https://github.com/Olanetsoft/agent-lookout.gitcd agent-lookoutnpm install
  3. 3

    Start it

    It prints an address, normally http://localhost:5173. Open it, and your sessions appear within a few seconds. 

    npm run dev

The README has every step, with what each command prints. The guide explains each part of the screen.

What it does today

It watches, it jumps, and it notifies you if you ask it to.

Runs on
macOS, as a local page in your browser.
Finds
Claude Code and Codex sessions already running, in a terminal, in VS Code or in a desktop app.
Claude Code
Shows which sessions are waiting for you, why, and for how long.
Codex
Shows a session as working, idle or finished. Codex does not record that it is waiting, so Agent Lookout cannot show it. Codex support is new: it has been checked with the Codex desktop app, and not yet with the Codex CLI or its IDE extension.
Notifications
Off until you turn them on in Settings. Then your browser shows one when a Claude Code session starts waiting, with the session’s name and the reason, and it is cleared when the session moves on. With no dashboard tab open, Agent Lookout shows them itself for as long as it keeps running. Nothing is sent off your Mac.
Jump
Opens a Claude Code session that runs in VS Code. It finds the session only when its folder is open in the VS Code window that has focus. Codex sessions, and Claude Code sessions in a terminal or the desktop app, have no Jump button.
Controls
None. It only watches: there are no approve, stop or pause buttons.
