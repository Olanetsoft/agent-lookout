It shows which one needs you

A Claude Code session that stops to ask moves to the top, with what it is asking and a timer, and the lamp lights on every view.

Nothing needs you the lamp in the mark is out
A session is waiting the lamp is lit, on every view

Codex does not record that it is waiting, so a Codex session shows as working, idle or finished. An Antigravity CLI session moves to the top while it asks to approve a tool, and shows as working while it asks you a question.

By default, it sends nothing anywhere.

No telemetry, no analytics, no account. The one exception is the Mac app’s daily check on GitHub for a newer version. It sends nothing about your sessions, and Settings turns it off. Email, a webhook, phone pushes, pull requests through your own gh and other machines over your own ssh stay off until you set them up. How to get it

Download the Mac app, or start Agent Lookout with Node.js in one of the other three ways and open it as a page in your browser.

View on GitHub
  1. 1

    Download the Mac app

    Download the disk image for Apple silicon or for Intel from the latest release on GitHub, open it and drag Agent Lookout to Applications. It needs macOS 13 Ventura or later, and no Node.js.

    The first time you open it, macOS says “Agent Lookout” Not Opened: press Done, then Open Anyway in System Settings › Privacy & Security. Kept in Applications, it updates itself from later releases.

  2. 2

    Start it with one command

    You need Node.js 22.12 or newer, and Claude Code, Codex or the Antigravity CLI. 

    npx agent-lookout

    The first time, npm asks Ok to proceed? (y): press Enter, and it downloads under 2 MB. Then it prints Agent Lookout is running at http://127.0.0.1:4777. Open that address, and your sessions appear within a few seconds. It listens on this machine only and runs until you press Ctrl+C. --port picks another port, and --open opens the page in your browser. To update, run npx agent-lookout@latest.

  3. 3

    Let your coding agent start it

    Paste the prompt in the README’s Install with your agent into Claude Code, Codex or another coding agent. It checks your Node.js, starts Agent Lookout with npx and checks that it answers. When the agent’s session ends, Agent Lookout can stop with it. If the page then says it has stopped updating, run npx agent-lookout yourself.

  4. 4

    Run it from the repository

    Run it this way to read or change its code. It needs the same Node.js.

    git clone https://github.com/Olanetsoft/agent-lookout.git
cd agent-lookout
npm install
npm run build
npm start

    npm start prints the same address, http://127.0.0.1:4777. To update, run git pull, then npm install and npm run build again.

The install guide has every step, with what each command prints. The guide explains each part of the screen.

What it does today

It watches your sessions. For Claude Code it also acts, only when you press a button or set a rule.

What it watches

  • Claude Code, Codex and Antigravity CLI

    Sessions already running appear with no setup. It never starts one.

  • Your own agents

    Any agent that writes a small status file appears beside them.

  • Branches and boards

    Each session’s git branch, as a list, by repository or as a board, with a search.

  • Pull requests

    Once on, each branch’s pull request and its checks, through your own gh.

  • History

    The Events log and charts are kept for 8 days, across restarts.

How it tells you

  • Needs you

    A Claude Code session that stops to ask, or an Antigravity CLI one waiting for approval, moves to the top, with a timer.

  • Last message

    Open a Claude Code session to read what it last said, as plain text. It is read only while you look, and Agent Lookout never sends it anywhere on its own.

  • Notifications

    Off until you turn them on. Then your browser, or your Mac, tells you.

  • Email, webhook and phone

    An email, a post to a Slack-compatible webhook, or a push to your phone through ntfy or Pushover, once a session has waited a minute. Off until you set it up.

  • Time rules

    Reminders of long waits, when idle turns stale, and quiet hours. Off until you turn them on.

What you can do

Claude Code

On Windows, only Jump to VS Code. Why

  • Allow or Deny

    With the plugin, see the whole command and answer from the page, or from the Mac app’s notification and menu bar.

  • Permission rules

    Always allow, ask or deny a kind of prompt, such as npm test:*. None until you add one.

  • Jump

    Takes you to the session in VS Code, its tmux pane, or its Terminal or iTerm2 tab.

  • Stop

    Ends a session once you confirm. Its conversation is kept.

  • Resume

    Copies the command that continues a finished background job or a session you stopped.

Where it runs

  • Mac app

    Counts waiting sessions in the menu bar and the Dock, and updates itself. macOS 13 or later.

  • Another machine

    Run Agent Lookout there and name it, and its sessions show beside yours, through your own ssh.

  • From a terminal

    agent-lookout status prints who needs you, and agent-lookout mcp lets an agent ask. Both only read. The Mac app opens no port, so they need npx agent-lookout running too.

  • Linux and Windows

    In your browser. Checked in CI, not yet by a person at a desktop.

Codex shows as working, idle or finished: it does not record when it waits. Checked with the Codex desktop app, not yet its CLI or IDE extension. An Antigravity CLI session that asks you a question shows as working. Antigravity CLI support is new: built from agy 1.3.1 and checked against one conversation. The Antigravity desktop app’s conversations do not appear. What it does not do yet
