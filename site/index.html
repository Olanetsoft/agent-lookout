Features

01 Sessions

Your sessions, with no setup

Claude Code, Codex, Antigravity, the Antigravity CLI, Mistral Vibe, Gemini CLI, OpenCode, Qwen Code and Hermes Agent sessions show up on their own, with their folder, branch and status. Any other agent can join by writing one small file per session.

More on sessions →

02 Needs you

See which one is waiting on you

A session that stops for your permission or an answer moves to the top, longest wait first, with a timer, and Agent Lookout’s mark lights up amber. A Claude Code session also says what it is asking.

Claude Code reports every wait. Antigravity, the Antigravity CLI and status files report some, and the other agents none yet.

More on Needs you →

03 Allow or Deny

Answer without switching windows

When Claude Code asks to run a command, you see all of it and can Allow or Deny it from the page. The Mac app sets this up the first time it opens; with npx, add the plugin in Claude Code.

Claude Code only, on macOS and Linux.

More on Allow and Deny →

04 Notifications

Be told when a session needs you

Turn on notifications to be told when a session needs you, on a Mac even with no tab open. Email, a webhook, ntfy or Pushover can tell you too, once you set them up.

All off until you turn them on.

More on notifications →

05 Jump and Stop

Go straight to it, or stop it

Jump opens a Claude Code session where it runs: VS Code, a tmux pane, or a Terminal or iTerm2 tab. Stop ends one after you confirm, and Resume copies the command that picks it up again.

Claude Code only. On Windows, only Jump to VS Code.

More on Jump and Stop →

06 Sources

See what each agent can report

Agents record different things. Sources says what Agent Lookout reads for each one, and a table shows what each can and cannot report, so a missing signal is never taken for good news.

Pick how you run it

The same dashboard, three ways to start it.

The Mac app

macOS 13 or later · Apple silicon or Intel

  1. Download the .dmg for your Mac from the latest release: arm64 for Apple silicon, x64 for Intel.
  2. Drag it to Applications. It needs no Node.js.
  3. It is not signed yet, so the first time macOS stops it: press Done, then Open Anyway in System Settings › Privacy & Security.
  4. Its Dock icon and menu bar count the sessions that need you, and it updates itself when you say so.

With npx

Node.js 22.12 or later · macOS, Linux or Windows

$ npx agent-lookout

Then open http://127.0.0.1:4777. Your sessions appear within a few seconds.

To answer Claude Code’s permission prompts from the page, add the Claude Code plugin.

Install guide

With your coding agent

Claude Code, Codex or another agent

Paste this prompt. Your agent checks Node.js, starts Agent Lookout in the background and tells you what it printed.

Show the prompt 
Start Agent Lookout on this computer. First check that node --version
prints v22.12.0 or later. Then run npx --yes agent-lookout in the
background and leave it running.
It should print "Agent Lookout is running at http://127.0.0.1:4777".
If it prints anything else, or says the port is in use, stop and tell
me what it printed.

Do not use sudo, and do not set up email, a webhook, phone pushes,
pull requests or other machines. You are done when
curl -s http://127.0.0.1:4777/api/health prints {"ok":true and a
version number. Tell me what it printed.

An agent’s background command can end with its session. If the page stops updating, run npx agent-lookout yourself.

Questions

Which agents does it work with?
Claude Code, Codex, Antigravity, the Antigravity CLI, Mistral Vibe, Gemini CLI, OpenCode and Qwen Code, and any agent that writes a small status file. Support for Mistral Vibe, Gemini CLI, OpenCode and Qwen Code is new and not yet checked on a computer running them. What each agent can report
Does it send anything off my computer?
Nothing about your sessions, by default: no telemetry, no analytics, no account, and it listens on this computer only. The few exceptions, such as the Mac app’s daily check for a new version, are in Privacy.
Can it control my agents?
It never starts a session or sends one a message. It stops a Claude Code session only when you press Stop and confirm, and answers its permission prompt only when you press Allow or Deny, or a rule you set matches.
Does it run on Linux and Windows?
Yes, with npx. It is built and used on macOS. Linux and Windows are tested in CI. On Windows, Stop, Allow and Deny are not there, and OpenCode’s sessions are not read.
Why does macOS stop the app the first time?
It is not signed with an Apple Developer ID yet. Press Done, then Open Anyway in System Settings › Privacy & Security, and macOS remembers.
